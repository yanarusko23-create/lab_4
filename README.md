# Лабораторна робота №5 — CI/CD з GitHub Actions

[![Python CI Application](https://github.com/yanarusko23-create/lab_4/actions/workflows/python-app.yml/badge.svg)](https://github.com/yanarusko23-create/lab_4/actions/workflows/python-app.yml)

Репозиторій містить навчальний проєкт із простим Python-калькулятором та налаштованим CI-пайплайном для автоматичного тестування й перевірки якості коду.

## 📋 Функціонал

- Базові арифметичні операції: додавання, віднімання
- Модульні тести через `unittest`
- Автоматична перевірка якості коду через `flake8` (PEP8)
- Захищене зберігання конфіденційних даних через GitHub Secrets
- Захист гілки `main` від злиття без проходження CI

## 🚀 Запуск тестів локально

```bash
python -m unittest test_calculator.py
```

## 🔍 Перевірка стилю коду

```bash
pip install flake8
flake8 .
```
